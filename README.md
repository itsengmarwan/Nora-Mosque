# Nora Mosque — موقع المسجد

مستودع لموقع مسجد نورة سعد العبيد (نسخة عامة جاهزة للنشر).

تشغيل محلي وجاهزية للنشر:

1. ثبت الحزم:
   npm install
2. شغّل الخادم:
   npm start
3. افتح في المتصفح: http://localhost:3000

مزايا النسخة الحالية:
- واجهة عامة متجاوبة ومصممة للهواتف بشكل أساسي مع تحسينات مرئية.
- عرض مواقيت الصلاة، مكتبة صور، المصحف، معلومات الاتصال والموقع.
- PWA وService Worker موجود لتسريع التحميل والعمل أوفلاين.

نصائح للنشر:
- يمكنك نشر على Render/Netlify/Vercel. الخادم المستعمل هو `server_public.js` ويستخدم `npm start`.
- تأكدي من استخدام HTTPS (مزود الاستضافة يوفّر ذلك عادةً).
