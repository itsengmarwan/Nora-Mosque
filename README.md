# Nora Mosque — موقع المسجد

مستودع لموقع مسجد نورة سعد العبيد مع خادم بسيط للوحة الإدارة وإدارة الأخبار.

تشغيل محلي:

1. انسخ `.env.example` إلى `.env` وغيّر القيم الحساسة (JWT_SECRET و ADMIN_PASS).
2. ثبت الحزم:
   npm install
3. شغّل الخادم:
   npm start
4. افتح في المتصفح: http://localhost:3000

مميزات مضافة:
- PWA مع service worker و caching للعمل أوفلاين.
- إشعارات أذان عبر Service Worker.
- صفحة أخبار (عرض عام) + واجهة CRUD لإدارة الأخبار (محميّة بتوكن JWT).
- لوحة إدارة مبسطة لدخول المشرف، تغيير كلمة المرور، رفع ملفات.
- صفحة تبرعات إرشادية لصندوق التبرعات بالمسجد.

ملاحظات أمان:
- غيّر `JWT_SECRET` و `ADMIN_PASS` في `.env` قبل النشر.
- استخدم HTTPS عند النشر.
